# Statistics Projects 📊

Repository dedicated to laboratory exercises, scripts, and statistical data analysis developed during the **Statistics** course at the **University of Bergamo** (Computer Engineering, Year 2).

---

### 📂 Contents
* **Probability Distributions:** Simulations and calculations for discrete and continuous variables.
* **Data Analysis & Inference:** Descriptive statistics, hypothesis testing, and confidence intervals.
* **Scripts & Labs:** Practical implementations using Python / R.
